Interaction notes
· Tabs per assembly: Browse, Diff, unlimited. Middle-click closes.
· Changed-type pills appear on the tree, so the Browse and Diff tabs share one mental model.
· Ctrl+K searches .cs file names everywhere; F5 reloads all; Ctrl+Shift+E exports sources.
· Closing the window → tray; closing the last tab → app. Everything else (timeline, tray, reports) unchanged.
